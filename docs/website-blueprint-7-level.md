# Website-Blueprint: 7-Level-System

Wie mit Claude Code Websites entstehen, die nicht nach Standard aussehen. Kernidee: Das Modell ist nur Multiplikator — Qualität kommt aus Referenzen, Skills, Assets und Daten ("Mozart ohne Klavier"). Quelle: Jakobs Blueprint-PDF (Juli 2026). Ergänzt [workflow-neuer-kunde](workflow-neuer-kunde.md) Schritt 3 (Umsetzung).

## Die 7 Level (jede Stufe baut auf der vorigen auf)

1. **Grab & Go** (3/100) — Claude wie einen Chatbot benutzen. Zu vage, vermeiden.
2. **Screenshots/Referenzen** (10/100) — show, don't tell. Quellen: Godly, Landbook, Awwwards, Dribbble. Bild droppen + "nutze das als Referenz-Stil".
3. **Design-Skills** — Instruktionspakete aktivieren: frontend-design, ui-ux-pro-max, shadcn/ui u. a. → auf PC 1 größtenteils installiert, siehe dem Skill-Katalog (Claude-Brain-Vault).
4. **Bild & Video** — Asset-Generierung (OpenArt: Nano Banana 2 für Bilder; Kling/Seedance für Video, Start=End-Frame für Loops). Echter Unlock: Bildgenerator per MCP direkt an Claude.
5. **UI Snapping** — fertige Komponenten übernehmen statt neu erfinden: 21st.dev, Codepen, Magic UI, Mobbin. URL oder Code an Claude geben. → 21st.dev Magic MCP auf PC 2 registriert.
6. **Daten** — Firecrawl (MCP): Brand-Identity extrahieren, Gewinner/Verlierer der Nische researchen → Scoring-Matrix → konvertierende Struktur & CTAs. "Schön ohne Daten = Ferrari ohne Motor."
7. **Design-Extraktion** (stärkste Stufe) — Design-DNA (Typografie, Farben, Regeln) einer Top-Referenz per Extractor ziehen und one-shot bauen. **Prinzipien extrahieren, nicht kopieren** (Urheberrecht! [no-gos](no-gos.md)).

## Master-Workflow

Ziel beschreiben → Referenzen sammeln → Design-Skills aktivieren → Assets via MCP generieren → Komponenten snappen → Daten/Scoring → Design-DNA extrahieren & one-shot bauen → **vor Live: [recht-checkliste-website](recht-checkliste-website.md)** (Impressum, DSGVO, Consent, Google-Fonts-Falle, BFSG).

## Häufigste Fehler

Chatbot-Nutzung · beschreiben statt zeigen · ohne Skills arbeiten · nur Text/Grafik · Komponenten neu erfinden · schön ohne Daten · kopieren statt extrahieren.
